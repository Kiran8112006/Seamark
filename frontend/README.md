# SEAMARK Frontend

Next.js 16 web application for the SEAMARK ocean resource exploration platform.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Copy the environment configuration:
   ```bash
   cp .env.example .env.local
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser.

For complete project documentation, system architecture, and backend instructions, refer to the root [README.md](../README.md).
